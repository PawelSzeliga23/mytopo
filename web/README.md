# topo — frontend

Aplikacja React + Vite + TypeScript (Tailwind 4, shadcn/ui, MapLibre).

## Uruchomienie

```
cd web
npm install
npm run dev
```

Aplikacja oczekuje API na `localhost:8000` (żądania `/api` są przekazywane przez serwer deweloperski).

## Polecenia

- `npm test` — testy (Vitest)
- `npm run build` — build produkcyjny do `dist/`
